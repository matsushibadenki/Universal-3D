# USD追記時の配置索引の事前構築

2026-11-04。🟢 [Done] USD追記後の配置索引をRustワーカーで準備し、文書への追記と同じ確定処理で採用する。既存の文書、Undo／Redo、自己完結したv3保存を維持する。

## 準備と採用

SDK変換の完了後にEditorロックを短時間取得し、現在文書の属性スナップショット、次の物体ID、文書Stamp、既存の形状索引のArc、合算予算を取得する。Meshの頂点データは複製しない。変換待ち中に完了した通常編集はこの時点の文書へ含まれる。

ワーカーのAppendPlanが追加物体とアセットIDを確定し、フレーミング用境界の走査・検証も行う。準備済みの形状索引は不変Arcで共有する。未準備形状の頂点／エッジ／面索引と、既存配置・追加配置を合わせた配置木を構築する。非表示メッシュの形状準備、表示プリミティブ、ミラー、回転・shearを含む。別の文書へ索引だけを取り付けないよう、準備結果は追記候補文書そのものを所有する。

採用時はEditorロック下でStampとドラッグ状態、最新の合算予算、取消を照合する。準備中に通常編集・Undo／Redo・文書置換があれば拒否し、追記しない。選択・カメラ・フレーム・ツールの変更だけなら許可する。追記は一つの履歴項目として記録し、その時点の選択をUndoで復元する。従来どおり新しい物体を選択して取り込み範囲へフレーミングする。

完成したSceneIndexと形状キャッシュを現在のepoch／描画revisionへ採用する。文書の丸ごと置換や履歴消去は行わない。最初のスナップで配置木や形状を再構築せず、その後の変更は既存の変更IDによる局所更新へ戻る。旧スナップショットのArcは有効なまま保護する。Rust内で索引を保持し、大容量の配置配列や頂点をIPCへ追加しない。

## 進捗・容量

既存のUSD操作IDと取消フラグを使う。Validate、Vertices、Surfacesに続きInstances工程を報告し、全候補物体数を工程の総数とする。画面下端とUSDダイアログの既存表示を利用する。取消・予算超過・競合で候補を破棄すると構築予約も解放する。

新規構築予算は、今回不足している形状と、追記後の全配置木を対象とする。再利用する形状は既存索引の計上に含まれるため、構築予約へ重複して加えない。構築中・採用前の合算再判定と予約の共有を維持する。`last_preparation`へ`reused_shapes`と`reused_buffer_bytes`を追加し、候補全体の保持容量と今回の予約を区別する。`memory`は共有形状を含む候補全体、`budget.triangles/shapes`は新たに準備する分を示す。

## 検証

- 未準備の既存シーンへ追記し、最初のスナップで物体訪問・形状構築・全体同期が増えないこと、頂点／エッジ／面候補、Undo／Redoを検証。
- 1万配置の合成シーンで、非表示・ミラー・回転・shearを含む既存形状を同じArcのまま共有し、追加形状だけを予約することを検証。旧索引の配置数・有効性も維持。
- 選択／ビュー変更の許可、現在の選択のUndo復元、予算の完全一致と1byte超過、準備前／採用前取消、編集／文書置換の競合拒否、文書・履歴・既存キャッシュの保持と予約解放を検証。
- 開発環境の実USD SDKで、合成USDAのquadを変換して追記。2三角形、追加1物体、既存物体を含む準備済み配置2。最初のスナップの物体訪問・形状構築はともに0件。保存内容のUndo／Redo一致も確認。
