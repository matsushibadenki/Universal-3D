## Undo履歴の軽量化

- Undo/Redo途中の選択変更は従来のスナップショット履歴と同じ復元動作を維持。履歴100件、無変更時のRedo保持、不正更新の拒否、新編集時のRedo破棄を確認。

- 1万オブジェクトで同じ1個を100回編集するテストでは、履歴保持は前後合計200オブジェクト。Vec容量・Objectサイズ・文字列容量から算出した履歴割当量は32,064 bytes。従来の100文書分のObject配列だけの概算は96,000,000 bytes（文字列と配列ヘッダを除く）。これはプロセスRSSやピークメモリの実測ではない。

## revision／変更IDによるCPU走査削減

## 2026-10-15 中央GPUビューポートと直接操作

- macOSではWKWebViewの背面にクリップ付きNSView／CAMetalLayerを配置し、wgpu Surfaceから直接描画。GPUデータはRust側に保持し、IPCはCSS表示領域・入力命令・状態のみ。AppKit操作はメインスレッドで実行し、MetalレイヤーとSurfaceの寿命を保持する。
- ResizeObserver、スクロール、表示状態、ネイティブリサイズ／DPI通知から領域を同期。CSS viewportとWKWebViewの高さ差を使ってタイトルバーの32ptずれを補正。部分クリップ時も投影のフルサイズを保持し、隠れた領域は描画を停止する。
- Alt＋左／中／右ドラッグを回転／パン／ドリーへ割り当て、ホイールとFフォーカスを追加。入力命令は直列化し、連続する同種のカメラ差分を集約する。カメラの注視点・視点計算はRustが所有し、Document履歴には追加しない。
- Rustのレイ／三角形交差で最前面を選択。非表示を除外し、回転・負スケール・ミラーを適用。球による粗い除外の後に形状を判定する。クリック時はオブジェクト走査を行うため、大規模シーンの空間索引は今後の課題。
- 通常Rustテスト32件、Clippy全ターゲット検査、TypeScript／Viteビルド、同期JavaScriptテスト4件、Tauri debug .appバンドルが成功。今回追加した6件で座標／DPI変換、クリップ、不正領域、相対カメラ操作、ピッキング、狭いアスペクト比のフォーカスを確認。
- MetalオフスクリーンGPUテスト1件成功。通常サンドボックスではアダプタを取得できなかったため、許可されたサンドボックス外で実行して成功した。
