# Universal 3D

ThreeXとの協調方針とエンジン境界は [docs/engine-coordination.md](docs/engine-coordination.md) に記録しています。参照用シンボリックリンクへのビルド・実行依存は追加しません。

Tauri 2 + Rust + wgpuによる統合3D制作アプリの初期実装です。現段階は基本シーン編集ができるMVPであり、Maya・3ds Max相当の全機能はまだ備えていません。

## 起動

```sh
npm install
npm run tauri dev
```

macOS検証用アプリ: `src-tauri/target/debug/bundle/macos/Universal 3D.app`。macOSでは起動時に中央パネルへRust/wgpuのGPUビューを表示します。Windows/Linuxは独立GPUウインドウを開く方式です。

```sh
npm run build
npm run test:sync
cargo test --manifest-path src-tauri/Cargo.toml
npm run tauri build -- --debug --bundles app
```

`npm run dev` はブラウザでUIを確認するためのプレビューです。ブラウザでは編集操作を無効化しています。

## 使い方

1. 立方体・球体・平面を追加し、OutlinerまたはGPUビューでクリック選択します。
2. Channel Boxで位置・回転（度）・スケール・名前・表示を変更します。数値はEnterまたはフォーカス移動で確定します。
3. ワールドX軸ミラーは原形状を保ったまま複製を描画します。
4. macOSのGPUビューはAlt＋左ドラッグで回転、Alt＋中ドラッグでパン、Alt＋右ドラッグまたはホイールでドリー。Fで選択対象へフォーカス、Shift＋Spaceで中央ビューを拡大・復元します。カメラスライダーも利用できます。
5. Qは選択、Wは移動ツール。赤／緑／青の矢印をドラッグすると選択した座標系のX／Y／Z軸方向、中央の四角は画面に沿って移動します。Escapeで取消、ドラッグ終了後は1回のUndoで開始前へ戻せます。変形中は他の編集・保存／読込を保留します。Eは回転ツールでX／Y／Zのリングと画面軸の外周リング、Rはスケールツールで軸ハンドルと中央の均等拡縮ハンドルを操作します。回転・スケールもEscape取消と1回のUndo／Redoに対応し、スケールの正負は維持します。
6. ビューポート上部でワールド／ローカルを切り替えます。座標系はツールごとにセッション内で保持します。磁石ボタンで相対ステップスナップを有効化し、隣の刻みを選びます。初期値は移動1、回転15度、拡縮倍率10%刻み。Jを押している間は有効／無効を反転します。相対モードの中央移動は画面平面内でスナップします。
7. パネル見出しの分離ボタンでフローティング、分離パネルのドッキングボタンで元の位置に戻します。
8. 保存／開くは `.u3d` JSON形式。Cmd/Ctrl+Z、Shift+Cmd/Ctrl+Z、Cmd/Ctrl+Sを利用できます。

移動ツール（W）にはXY／YZ／XZの平面ハンドルがあります。ビューポート上部の「相対／グリッド」と磁石ボタンでスナップを設定できます。グリッドはワールド原点基準で、軸は1座標、平面は2座標、中央は奥行きを含む3座標を揃えます。ローカルへ切り替えると相対スナップに戻ります。1回のドラッグは1回のUndoで戻せ、Escapeで取り消せます。


頂点へ合わせるにはWで移動ツールにし、Vを押してから選択物の頂点をドラッグします。「頂点スナップ」モードと磁石ボタンでも有効化できます。別の表示オブジェクトの頂点へ14px以内で吸着し、中央ハンドルはピボットを3次元で一致、軸・平面ハンドルは拘束方向だけを変更します。水色が移動元、黄色が吸着先です。頂点が重なる場合は画面距離が近い候補を優先し、同距離なら手前を選びます。選択物自身は吸着先から除外します。Vは相対／グリッドスナップより優先します。

移動の「エッジ／面」モードと磁石ボタンで、選択物のピボットまたは直接つかんだ頂点を合わせられます。エッジはカーソル14px以内の線分上、面はカーソル直下の最も手前の表面へ吸着します。Jで一時反転、Vで頂点へ一時切替、Escapeで取消、1ドラッグ単位のUndo／Redoに対応します。軸・平面ハンドルの拘束が優先され、拘束時は対象へ接触しない場合があります。回転は変更しません。新規USDは元のポリゴン辺を保持し、境界情報のない旧メッシュは境界・折れ目を再構成します。

RのXY／YZ／XZ平面ハンドルでは2軸を同じ倍率で拡縮します。ローカルは対応する2つのscaleチャンネル、ワールドは対応する2つのワールド方向を変形します。負スケールを維持し、Undo／Redo・Escape取消に対応します。

ワールド軸で回転済みの物体を非均等に拡縮すると、形状を正確に保持するためシアーが生じます。シアーがある場合はChannel BoxにXY／XZ／YZを表示します。保存は`.u3d` v2形式です。従来のv1ファイルは読み込めますが、v2は旧アプリでは開けません。

## データ所有と描画

- `src-tauri/src/document.rs`: RustがDocument、選択、履歴、カメラ、現在フレーム、パネル配置を所有。Undo履歴は変更範囲の前後データを保存し、未変更オブジェクトを複製しません。履歴上限は100件。
- `src-tauri/src/editor.rs`: UI非依存の編集コマンド実行、検証とUndo/Redoへの接続。
- `src-tauri/src/main.rs`: コマンド呼出し、全ウインドウへの状態通知、保存／読込、ウインドウ管理。
- `src-tauri/src/renderer.rs`: Rustによるプリミティブ生成・変換、wgpuによる深度付きGPU描画。
- `src-tauri/src/affine.rs`: シアーを含むアフィン行列、ワールド軸スケールの分解と数値限界の処理。
- `src-tauri/src/snapping.rs`: 共有形状の頂点BVH、変更ID／revisionで更新するインスタンス索引、カーソル周辺の頂点探索。索引をジェスチャー間で再利用し、カメラ変更時も頂点を再生成しません。
- `src-tauri/src/surface_snap.rs`: 元ポリゴン境界／旧形状のエッジ再構成、線分上の遠近補正、三角形交差、共有BVHによる表面探索。
- `src-tauri/src/spatial.rs`: 反射・シアーに対応した境界と、高さを保つ動的境界木。追加・削除・変形で対象の葉と祖先だけを修復します。
- `src-tauri/src/gizmo.rs`: 移動・回転・スケールハンドルの投影・当たり判定・拘束計算、Rust所有のドラッグ状態。
- `src-tauri/src/viewport.rs`: macOSのネイティブMetalレイヤー接続、CSS座標／DPI変換、クリッピング。
- `src/Viewport.tsx`: 表示領域の通知、ポインター入力、カメラ命令の直列化・集約。
- `src-tauri/src/scene.wgsl`: GPUシェーダー。
- `src/`: ReactのUI。ウインドウはDocumentを所有せず、共有状態のスナップショットを表示し、命令を送ります。入力途中の文字列など表示のための一時状態のみ保持します。

IPCは命令とオブジェクトの属性のみ。頂点・ピクセル・フレームデータはJavaScriptへ転送しません。初期版は操作時に再描画する構成です。プリミティブ形状は共有キャッシュ、頂点バッファは容量内で再利用し、深度テクスチャはサイズ変更時のみ再生成します。モデル／カメラ行列の適用と陰影計算はGPU側で行い、形状別に最大3回のメッシュ描画でプリミティブとミラーを描画します（グリッドは別の1回）。取り込んだUSDメッシュは専用バッファと描画バッチを持ちます。形状はGPUへ一度だけ転送し、各表示インスタンスは80バイトの行列・色を持ち、前回値と比較して連続する変更範囲のみ転送します。バッファ拡張時は全表示インスタンスを初期化します。CPU側はオブジェクトの位置・回転・スケールを比較し、変更時のみ行列を組み立てます。カメラ行列も変更時のみ転送します。Rustは描画用revisionと直近128件の変更ID履歴を保持し、通常の単体編集・選択では対象IDのTransform比較とインスタンス更新だけを行います。カメラ／フレームだけの変更ではオブジェクトを走査しません。Documentはrevision付きの変更範囲で通知し、初期表示・ファイル置換・通知欠落時は全量スナップショットで同期します。追加・削除では文書の変更区間以降の位置索引だけを修復し、最大IDは順序付き集合から取得します。形状／表示／ミラー切替も対象IDのインスタンスを挿入・削除し、対象形状バッチの後続だけを詰め直します。文書順を維持するため、その後続区間は更新が必要です。全体再構築は初期化・文書置換・描画側の履歴欠落時に限ります。通常の編集検証・ID検索もID索引を使用します。

頂点スナップは、形状ごとに重複頂点を1回だけ除去してBVHを共有し、オブジェクト境界からカーソル周辺の頂点だけ探索します。単体編集・Undo／Redo・追加削除は変更IDから索引を局所更新します。同じrevisionとカメラ／サイズだけの変更では全物体走査・頂点の再生成を行いません。文書置換・変更履歴欠落時にはインスタンス索引を再構築します。USD取り込み・文書読込・復旧では、参照メッシュの頂点・エッジ・面索引をワーカー内で事前構築し、読込完了後の最初のスナップで再生成しません。構築時間は読込処理に加算されます。直接コアAPIで追加した未準備形状には遅延構築も残します。計測条件と数値は[索引の性能計測](docs/snap-index-performance.md)と[検証記録](docs/verification.md)に記載しています。

## OpenUSD / Hugging Face

「ファイル → OpenUSDを読み込む…」でローカルUSD／USDA／USDC／USDZ、または公開SimReadyパッケージのURLを取り込めます。階層変換・単位を反映した静止メッシュとして追加し、Undo／Redo・変形・選択・v3文書への保存に対応します。テクスチャ／MDL、物理、アニメーション評価は未対応です。

解析には公式 `usd-core==26.11` を利用します。この開発環境のランタイムは準備済みです。別環境のセットアップ、対応範囲、検証アセットは[OpenUSDガイド](docs/openusd.md)を参照してください。

## 検証と制限

macOSでwgpu描画、追加、Transform変更、Undo/Redo、Inspector分離と再ドッキング、分離パネルからのミラー変更、保存／再読込を確認しました。現在のRust通常テスト99件、Metal GPUテスト2件、JavaScript同期テスト10件、OpenUSD Pythonテスト5件が成功。UIは英語・日本語・简体中文の320/375/414/768px幅で横のはみ出しを検査しています。OpenUSD取り込みは3言語の375/1280px UIとmacOS実アプリで確認しています。

macOSは中央GPUビューへの埋め込み・クリック選択・カメラ操作を実装済みです。Windows/Linuxの中央埋め込み、ドラッグで任意位置へのドッキング、面中心／エッジ中点へのスナップ、面法線への回転合わせは未実装です。macOSの透過WebViewはTauriのmacos-private-apiを使用し、Mac App Store配布への適合確認は未実施です。Timelineは共有フレーム指定のみで、キーフレーム・再生・アニメーション評価は未実装です。現在の固定プリミティブに対するミラーは、汎用Modifier Stackの最初の足場です。

未保存の文書を開く時とメインウインドウを閉じる時とCmd+Qで終了する時には破棄確認を表示します。OSの強制終了・プロセス停止には、30秒間隔の復旧用コピーからの復元に対応します。検証用ビルドはデバッグ版で、配布用の署名・公証は行っていません。

設計図と確認結果: [docs/verification.md](docs/verification.md)。進捗: [ROADMAP.md](ROADMAP.md)。

追加・更新・削除はRust側で対象範囲を直接変更し、一時Document全体コピーを作りません。履歴と通知には変更範囲だけを保持します。保存用の安定スナップショットと初期／復旧用スナップショットでは全量コピーを使用します。

Scene/Inspector/Timelineのドック／フローティング状態は、OSのアプリ設定ディレクトリ内の `workspace.json` に保存し、次回起動時に復元します。不正・未対応バージョンの設定は全パネルをドックした既定状態へ戻します。位置・サイズとドラッグによる任意ドック配置の保存は未実装です。ワークスペース設定は文書の保存やUndo履歴とは独立しています。

## 自動保存と復旧

変更がある文書は、Rust側で30秒間隔の復旧用コピーを保存します。元の `.u3d` には上書きしません。異常終了後は起動時の「文書の復旧」から未保存コピーとして戻せます。ステータスバーの盾／履歴アイコンで保存時刻・候補・エラーを確認できます。詳しくは[保存・復旧の仕様](docs/recovery.md)を参照してください。
