# Universal 3D

ThreeXとの協調方針とエンジン境界は [docs/engine-coordination.md](docs/engine-coordination.md) に記録しています。参照用シンボリックリンクへのビルド・実行依存は追加しません。

Tauri 2 + Rust + wgpuによる統合3D制作アプリの初期実装です。現段階は基本シーン編集ができるMVPであり、Maya・3ds Max相当の全機能はまだ備えていません。

## 起動

```sh
npm install
npm run tauri dev
```

macOS検証用アプリ: `src-tauri/target/debug/bundle/macos/Universal 3D.app`。macOSでは起動時に中央パネルへRust/wgpuのGPUビューを表示します。Windows/Linuxは独立GPUウインドウを開く方式です。

```sh
npm run build
npm run test:sync
cargo test --manifest-path src-tauri/Cargo.toml
npm run tauri build -- --debug --bundles app
```

`npm run dev` はブラウザでUIを確認するためのプレビューです。ブラウザでは編集操作を無効化しています。

## 使い方

1. 立方体・球体・平面を追加し、OutlinerまたはGPUビューでクリック選択します。
2. Channel Boxで位置・回転（度）・スケール・名前・表示を変更します。数値はEnterまたはフォーカス移動で確定します。
3. ワールドX軸ミラーは原形状を保ったまま複製を描画します。
4. macOSのGPUビューはAlt＋左ドラッグで回転、Alt＋中ドラッグでパン、Alt＋右ドラッグまたはホイールでドリー。Fで選択対象へフォーカス、Shift＋Spaceで中央ビューを拡大・復元します。カメラスライダーも利用できます。
5. パネル見出しの分離ボタンでフローティング、分離パネルのドッキングボタンで元の位置に戻します。
6. 保存／開くは `.u3d` JSON形式。Cmd/Ctrl+Z、Shift+Cmd/Ctrl+Z、Cmd/Ctrl+Sを利用できます。

## データ所有と描画

- `src-tauri/src/document.rs`: RustがDocument、選択、履歴、カメラ、現在フレーム、パネル配置を所有。Undo履歴は変更範囲の前後データを保存し、未変更オブジェクトを複製しません。履歴上限は100件。
- `src-tauri/src/editor.rs`: UI非依存の編集コマンド実行、検証とUndo/Redoへの接続。
- `src-tauri/src/main.rs`: コマンド呼出し、全ウインドウへの状態通知、保存／読込、ウインドウ管理。
- `src-tauri/src/renderer.rs`: Rustによるプリミティブ生成・変換、wgpuによる深度付きGPU描画。
- `src-tauri/src/viewport.rs`: macOSのネイティブMetalレイヤー接続、CSS座標／DPI変換、クリッピング。
- `src/Viewport.tsx`: 表示領域の通知、ポインター入力、カメラ命令の直列化・集約。
- `src-tauri/src/scene.wgsl`: GPUシェーダー。
- `src/`: ReactのUI。ウインドウはDocumentを所有せず、共有状態のスナップショットを表示し、命令を送ります。入力途中の文字列など表示のための一時状態のみ保持します。

IPCは命令とオブジェクトの属性のみ。頂点・ピクセル・フレームデータはJavaScriptへ転送しません。初期版は操作時に再描画する構成です。プリミティブ形状は共有キャッシュ、頂点バッファは容量内で再利用し、深度テクスチャはサイズ変更時のみ再生成します。モデル／カメラ行列の適用と陰影計算はGPU側で行い、形状別に最大3回のメッシュ描画で全オブジェクトとミラーを描画します（グリッドは別の1回）。形状はGPUへ一度だけ転送し、各表示インスタンスは80バイトの行列・色を持ち、前回値と比較して連続する変更範囲のみ転送します。バッファ拡張時は全表示インスタンスを初期化します。CPU側はオブジェクトの位置・回転・スケールを比較し、変更時のみ行列を組み立てます。カメラ行列も変更時のみ転送します。Rustは描画用revisionと直近128件の変更ID履歴を保持し、通常の単体編集・選択では対象IDのTransform比較とインスタンス更新だけを行います。カメラ／フレームだけの変更ではオブジェクトを走査しません。Documentはrevision付きの変更範囲で通知し、初期表示・ファイル置換・通知欠落時は全量スナップショットで同期します。追加・削除では文書の変更区間以降の位置索引だけを修復し、最大IDは順序付き集合から取得します。形状／表示／ミラー切替も対象IDのインスタンスを挿入・削除し、対象形状バッチの後続だけを詰め直します。文書順を維持するため、その後続区間は更新が必要です。全体再構築は初期化・文書置換・描画側の履歴欠落時に限ります。通常の編集検証・ID検索もID索引を使用します。

## 検証と制限

macOSでwgpu描画、追加、Transform変更、Undo/Redo、Inspector分離と再ドッキング、分離パネルからのミラー変更、保存／再読込を確認しました。現在のRust通常テスト32件、Metal GPUテスト1件、JavaScript同期テスト4件が成功。UIは英語・日本語・简体中文の320/375/414/768px幅で横のはみ出しを検査しています。

macOSは中央GPUビューへの埋め込み・クリック選択・カメラ操作を実装済みです。Windows/Linuxの中央埋め込み、ドラッグで任意位置へのドッキング、ギズモは未実装です。macOSの透過WebViewはTauriのmacos-private-apiを使用し、Mac App Store配布への適合確認は未実施です。Timelineは共有フレーム指定のみで、キーフレーム・再生・アニメーション評価は未実装です。現在の固定プリミティブに対するミラーは、汎用Modifier Stackの最初の足場です。

未保存の文書を開く時とメインウインドウを閉じる時とCmd+Qで終了する時には破棄確認を表示します。OSの強制終了・プロセス停止に備える自動保存は未実装です。検証用ビルドはデバッグ版で、配布用の署名・公証は行っていません。

設計図と確認結果: [docs/verification.md](docs/verification.md)。進捗: [ROADMAP.md](ROADMAP.md)。

追加・更新・削除はRust側で対象範囲を直接変更し、一時Document全体コピーを作りません。履歴と通知には変更範囲だけを保持します。保存用の安定スナップショットと初期／復旧用スナップショットでは全量コピーを使用します。

Scene/Inspector/Timelineのドック／フローティング状態は、OSのアプリ設定ディレクトリ内の `workspace.json` に保存し、次回起動時に復元します。不正・未対応バージョンの設定は全パネルをドックした既定状態へ戻します。位置・サイズとドラッグによる任意ドック配置の保存は未実装です。ワークスペース設定は文書の保存やUndo履歴とは独立しています。
